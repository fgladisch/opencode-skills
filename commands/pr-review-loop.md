---
description: Address review feedback on an open PR until LGTM
---

Wait for the complete review comment for the current pull request. Evaluate every finding, apply every accepted fix, and mark each addressed finding as resolved in the pull request. Post a pull request comment summarizing how you addressed the feedback, including the rationale for any finding you did not accept. After posting the comment, commit all resulting changes with the `commit` skill and push the branch. Repeat the review, fix, resolve, comment, commit, and push cycle until the review reports LGTM.
